# 🎓 FOR STUDENTS - How to Run This Project

## ✨ Normal Startup (When Everything Works)

```
Step 1: Double-click → start-project.bat
Step 2: Wait for build (shows progress)
Step 3: Browser opens automatically
Step 4: Start using the app!
```

---

## ⚠️ If You Get "Maven Setup Needed" Message

**Don't panic!** Choose one of these **easy** options:

### 🌟 Option 1: AUTO-FIX (Easiest - 3 Minutes)

**Perfect if you have internet access**

```
Step 1: Double-click → fix-maven.bat
Step 2: Wait for download (you'll see progress)
Step 3: When it says "SUCCESS", close the window
Step 4: Double-click → start-project.bat again
```

**That's it!** Maven is now installed forever. You won't see this error again.

---

### 💾 Option 2: OFFLINE FIX (Works Without Internet)

**Use this if your school/college blocks downloads**

#### Part A: On a Computer WITH Internet
```
Step 1: Open this link:
        https://dlcdn.apache.org/maven/maven-3/3.9.6/binaries/apache-maven-3.9.6-bin.zip

Step 2: Download the file (it's about 10 MB)

Step 3: Copy to USB drive
```

#### Part B: On THIS Computer (Without Internet)
```
Step 1: Plug in USB drive

Step 2: Copy the ZIP file to your Desktop
        (Must be on Desktop!)

Step 3: Double-click → install-maven-offline.bat

Step 4: When it says "SUCCESS", close the window

Step 5: Double-click → start-project.bat again
```

**Done!** Maven is installed. The project will now work.

---

Backend started ✓

## 📱 Using the App

- **Two colored windows will appear:**
  - BLUE = Backend Server
  - YELLOW = Frontend Server
  
- **⚠️ DON'T CLOSE THESE WINDOWS** while using the app

- **To stop the app:**
  - Close both colored windows
  - OR press Ctrl+C in each window

---

## 💡 Tips for Students

✅ **Do Option 1 first** - it's automatic and easiest

✅ **Only use Option 2** if Option 1 doesn't work (firewalls, etc.)

✅ **You only need to fix Maven once** - after that, `start-project.bat` always works

✅ **You can move this project anywhere** - it rebuilds automatically

✅ **Share the ZIP file** with classmates who have the same issue

## ❓ Questions?

**Q: Do I need to fix Maven every time?**  
A: No! Only once. After that, everything is automatic.

**Q: Can I delete the ZIP file after installing?**  
A: Yes! Once Maven is installed, you don't need the ZIP anymore.

**Q: What if both options fail?**  
A: Contact your instructor or lab technician - there might be system restrictions.
